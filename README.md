# 筝谱 · Guzheng Jianpu Editor

A browser editor for writing guzheng sheet music in jianpu (numbered notation).

Open `index.html`, or visit the GitHub Pages site for this repository.

## Features

- Notes 1–7 and rests, note lengths, dotted notes, octave dots, sharps and flats
- Bar lines placed automatically from the time signature; repeats, double and final bar lines (click a bar line)
- Chords and arpeggios
- Right- and left-hand guzheng techniques, in mainland symbols or Taiwan-style characters, with custom symbols
- Any number of parts per line (right hand, left hand, ensemble instruments), lined up by beat
- Per-bar beat counts, per-line bar counts, and resizable lines
- Playback with koto, harp or synthesized plucked-string sounds
- Scores save automatically in your browser; export to a printable page or a `.json` backup

Press `?` in the editor for all keyboard shortcuts.
